# Manisha Jena — Product Portfolio

Interactive product-management portfolio showcasing product work, experiments, research, writing, and personal journey.

## What's included
- Featured product-management case studies
- PayDay Hub interactive concept and external demo
- Flex product discovery, landing page, and GenAI simulator
- SleepyCat review-intelligence analysis
- Writing & research, including links to published Hevo Data articles
- Journey, About, and Contact pages

Project imagery is illustrative. Concept and prototype work is distinguished from shipped business results.

## Run locally
Open `index.html` in Chrome, Edge, Firefox, or Safari. This first deployment is a self-contained HTML file with embedded CSS, JavaScript, photos, project thumbnails, and resume. No Node.js installation, API key, or database is required.

## Deploy to Vercel
1. Open https://vercel.com/new and import the GitHub repository `Manisha-40/Portfolio`.
2. Use the **Other** framework preset.
3. Keep the Root Directory as `.` (repository root).
4. Enable Build Command override and leave the command empty. The site is static.
5. Leave Output Directory at `.` if Vercel asks for it.
6. Click **Deploy**.

After the repository is connected, pushing changes to `main` should trigger a production deployment.

## Notes
- Do not commit credentials or private account information.
- No Supabase or Gemini key is needed to host this portfolio; its linked demos are separate applications.
- Contact links are intentionally limited until explicitly approved.
