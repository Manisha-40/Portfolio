# Phasal Saathi — Sikkim farmer-first concept prototype

An interactive, WhatsApp-first demonstration of a shared coordination layer between organic farmers, FPOs, Krishi Vigyan Kendras (KVKs) and agricultural departments.

## Try it

Open `index.html` in a modern browser. No build step, API key, credentials, or backend are required.

## Demo features

- WhatsApp and optional application-style phone flows
- Language previews with explicit verification disclaimers
- Three farmer scenarios: schemes, crop concern, market-selling choices
- Rule-based illustrative net return calculations, voice-transcript demos, photo attachment preview
- Human review and escalation, low-network cases, and an institutional/business value panel

## Responsible demonstration

Every farmer, market quotation, recommendation, and workflow status in this concept is illustrative. No actual WhatsApp, KVK, FPO or government service is connected; no advisory is provided for real farming decisions. The prototype uses fieldwork-informed product design but is not a live deployed agricultural service.

## Deployment

This is a static site. Use Vercel **Other** with the project root configured to this folder, or place the folder in the static public root of an existing Vercel project.
